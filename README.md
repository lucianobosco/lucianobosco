### Tunnels Manager

Open your database tunnels with one click, and copy the connection string with another.
A GTK4 app for Google Cloud IAP tunnels, `kubectl port-forward` and `ssh -L`.

[![Tunnels Manager](https://raw.githubusercontent.com/lucianobosco/tunnels-manager/main/docs/screenshot.png)](https://github.com/lucianobosco/tunnels-manager)

Opening a tunnel is one command. Remembering which of fifteen local ports belongs to which
database, noticing that one died, and not leaving orphan processes behind is the actual
work — so that is what it does. Written with the logic kept out of the toolkit, which is why
it has 100% branch coverage without a single test opening a window.
